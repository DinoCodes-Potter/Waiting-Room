Features

Small app. Careful details.

Everything you need to stop babysitting progress bars, and nothing you don’t.

01

Watch any region

Select a rectangle on any connected display: a build log, a file transfer or an AI agent’s output.

02

Several watches at once

Every watch runs independently, with its own name, alert mode and sensitivity.

03

Fewer false alarms

A pixel only counts as changed if it differs from both of the previous two frames, so blinking cursors are ignored.

04

Reads the screen

On-device text recognition flags whether the output looks successful or like an error, and includes the last lines it read.

05

Native alerts

A banner on the watched display, a macOS notification and a chime, whichever display you’re looking at.

06

Light on resources

Capture pauses while the screen sleeps or the session is locked, and slows down in Low Power Mode.

Detection

Pixel-level, not paranoid

Each region is sampled every second. Adjust the sensitivity to see how noise is filtered while a real change still gets through.

Privacy

Your screen stays on your Mac

Screenshots are analysed locally and discarded. Text recognition uses Apple’s Vision framework. The whole app is a handful of Swift files, so you can check for yourself.

Install

Up and running in a minute

Requires a Mac with Apple silicon and macOS 14 (Sonoma) or later.

01

Drag it in

Open the DMG and drag Waiting Room into Applications. It lives in your menu bar as an hourglass.

02

Open anyway

It isn’t notarized yet, so macOS warns you once. Allow it under System Settings, Privacy & Security, Open Anyway.

03

Allow recording

Grant Screen Recording so it can compare pixels, then quit and reopen. Drag a box and you’re off.

git clone https://github.com/DinoCodes-Potter/Waiting-Room.git
cd Waiting-Room
swift build -c release
.build/release/WaitingRoom

FAQ

Good questions

Does my screen content leave my Mac?

No. Screenshots are analysed locally and discarded, text recognition runs on-device with Apple’s Vision framework, and the app makes no network calls.

Why does macOS warn me the first time I open it?

Waiting Room isn’t notarized yet, so macOS blocks the first launch. Allow it once under System Settings, Privacy & Security, Open Anyway.

Which Macs are supported?

Macs with Apple silicon running macOS 14 (Sonoma) or later, which the ScreenCaptureKit screenshot API requires.

Can I watch more than one thing?

Yes. Every watch runs independently, with its own name, alert mode and sensitivity.

How often does it check the screen?

Each region is captured every second, or every two seconds while a Stops watch is waiting for activity to begin. It slows down in Low Power Mode.

Why does it need Screen Recording permission?

To compare pixels in the region you select. Choose “Grant Screen Recording access…” in the menu, allow it in System Settings, then quit and reopen the app.

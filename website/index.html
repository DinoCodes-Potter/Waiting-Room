three windows,
three kinds of waiting.

Pick the window that matches what you're waiting for. You can open all three at once.

WINDOW 1
changing…still for 3s

Stops

For builds, uploads and agents. You hear about it when the region goes quiet and stays that way for as long as you set, from 2 to 60 seconds.

WINDOW 2
waiting…something appeared

Starts

For things that haven't begun. You hear about it the moment a quiet region starts to change.

WINDOW 3
every change

Any change

For pages and logs you want to follow. You hear about every change, with a short cooldown so it doesn't nag.

small things,
posted clearly.

Watch any region

Select a rectangle on any connected display: a build log, a file transfer or an AI agent's output.

Several watches at once

Every watch runs independently, with its own name, alert mode and sensitivity.

No blinking cursors

A pixel only counts as changed if it differs from both of the previous two frames, so cursors don't set it off.

Reads the screen

On-device text recognition says whether it looks like a success or an error, and quotes the last lines.

Alerts you will notice

A banner on the watched display, a macOS notification and a chime, whichever display you're looking at.

Quiet on resources

Capture pauses while the screen sleeps or the session is locked, and slows down in Low Power Mode.

pixel-level,
not paranoid.

Each region is sampled every second. Change the sensitivity and watch noise get filtered while a real change still gets through.

Quick answers. Anything missing, ask.

Ask on GitHub
Does my screen content leave my Mac?

No. Screenshots are analysed locally and discarded, text recognition runs on-device with Apple's Vision framework, and the app makes no network calls.

Why does macOS warn me the first time I open it?

Waiting Room isn't notarized yet, so macOS blocks the first launch. Allow it once under System Settings, Privacy & Security, Open Anyway.

Which Macs are supported?

Macs with Apple silicon running macOS 14 (Sonoma) or later, which the ScreenCaptureKit screenshot API requires.

Can I watch more than one thing?

Yes. Every watch runs independently, with its own name, alert mode and sensitivity.

How often does it check the screen?

Each region is captured every second, or every two seconds while a Stops watch is waiting for activity to begin. It slows down in Low Power Mode.

Is it free?

Yes. Waiting Room is free and open source under the MIT licence.

Does it work with more than one display?

Yes. You can select a region on any connected display, and the banner appears on the display you're watching.

What does an alert look like?

A banner on the watched display, a macOS notification and a chime. When it fires, the app reads the text in the region and says whether it looks like a success or an error.

Is there an Intel version?

The prebuilt app is for Apple silicon only. The source is open if you want to look into building it yourself.

How do I uninstall it?

Quit Waiting Room from the menu bar, then drag it from Applications to the Trash.

Why does it need Screen Recording permission?

To compare pixels in the region you select. Choose "Grant Screen Recording access…" in the menu, allow it in System Settings, then quit and reopen the app.
